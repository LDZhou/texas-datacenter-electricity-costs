# Reference analysis tables

These tables contain the accepted results used in the manuscript:

- `wholesale/`: capped wholesale-price attribution and seasonal unserved-energy
  summaries.
- `retailer/`: 5,000-path retail-provider summaries by zone and procurement case,
  using a $5,000/MWh price cap and a $2.601/MWh flat-load transmission charge.
- `siting_by_year.csv`, `siting_weather_year_mean.csv`: the representative
  interconnection experiments by weather year and their means.

`manifest.json` records file hashes. Matched branch-level engineering results
are in `../texas2k/reference_outputs/`. Model networks and API configuration
files are generated locally and excluded from Git.
